# Shared Calendar

Nick and Cam work off one shared Google Calendar. This note is the synced reference for how it's used — the underlying connection and setup live in [[../INTEGRATIONS/01-Google-Workspace]]; this page is about what actually goes on the calendar and why.

## What Goes On It

| Category | What It Covers | Cadence |
|---|---|---|
| Client meetings | Demo calls, kickoff calls, and ongoing check-ins with live clients and assigned prospects (see [[01-Nick-Profile]] and [[02-Cam-Profile]] for who's on which account) | As scheduled, ad hoc |
| Content review windows | The window between the Wednesday agent runs and Sunday's client preview email, when captions and graphics need a Nick/Cam pass | Wednesday 2:00 PM – Thursday |
| Client preview window | The 24 hours after Sunday's preview email, before Monday's posts go live | Sunday 5:00 PM – Monday |
| Deployment windows | When it's safe to ship — Friday's SEO Audit Agent run, and any manual site launches or domain cutovers | Friday 9:00 AM (recurring); ad hoc for launches |
| Sales outreach checkpoint | Monday morning review before that week's prospect emails send | Monday 9:00 AM |

The weekly rhythm above mirrors [[../AUTOMATIONS/00-Automation-Calendar]] almost exactly — the calendar exists to put human names and times on the same schedule the agents already run on, so neither Nick nor Cam is caught off guard by something that's about to ship or send.

## Why It's Shared Rather Than Split

Because every approval gate in this agency names both of them (see [[03-Roles-and-Responsibilities]]), a shared calendar is the only version that works — if Cam books over the Wednesday review window without Nick seeing it, that week's content review slips, and the same is true in reverse for deployment windows Nick might set without Cam's visibility into a client relationship he owns.
