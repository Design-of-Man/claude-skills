# Agency Content

The Design of Man's own marketing assets — pitch decks, proposal templates, and brand assets used to sell and onboard clients. This is the agency's content about itself, as distinct from anything produced *for* a client.

## What lives here

| Asset type | Description | Status |
|---|---|---|
| Pitch deck | Standard deck used on prospect calls — problem/solution, portfolio, pricing | To build — first version pending real portfolio proof (see [[../00-Case-Studies/README]]) |
| Proposal template | Scope + pricing template sent after a discovery call, one per engagement type (site build, migration, ongoing management) | To build |
| One-pager / capability sheet | Leave-behind for prospects who aren't ready for a full deck | To build |
| Brand assets | Logo files, color palette, type specimens, letterhead | To build — pull from [[../../TEMPLATES-BUILDS/01-Design-System]] |
| Case study slides | Client case studies formatted for the pitch deck | Waiting on [[../00-Case-Studies/README]] to have content to pull from |

Nothing here is filled in yet — the agency has been running on ad hoc decks and one-off proposals per prospect. As pitch materials get standardized, the finished, reusable versions land in this folder so the next pitch doesn't start from a blank page.

## Brand consistency

Every asset in this folder — deck template, proposal, one-pager, letterhead — should draw its colors, type, and component styling from the same source client sites do, not a separate "agency brand" invented on the side:

- [[../../TEMPLATES-BUILDS/01-Design-System]] — the design tokens, color palette, and typography system this folder's visual assets should match

Keeping agency-facing materials on the same design system as client-facing builds is itself part of the pitch: a design agency whose own deck looks inconsistent with its own design system is a bad look on a sales call.
